# tiny-sandbox Python SDK

Synchronous, standard-library-only client for the tiny-sandbox v1 HTTP API.
Requires Python 3.10 or newer and a running sandboxd with Docker.

Install from the repository: python3 -m pip install ./sandbox-python

See docs/sdk-python.md in the repository for the public contract, cancellation
and retry semantics, examples, compatibility policy and repeatable E2E checks.
